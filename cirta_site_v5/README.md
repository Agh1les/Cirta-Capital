# Cirta Capital website — clean rebuild

Upload the complete contents of this folder to the root of cirtacapital.com, replacing the previous website.

Main pages:
- `/` English homepage
- `/about.html` English About page
- `/fr/` and `/fr/about.html` French
- `/es/` and `/es/about.html` Spanish

The contact buttons use `mailto:contact@cirtacapital.com` and open the visitor's email client. All visible brand marks use the same three-arch Cirta logo.
